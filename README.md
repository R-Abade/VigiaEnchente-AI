# 🌊 VigiaEnchente

Sistema inteligente para **prevenção de enchentes e cálculo de rotas seguras**, utilizando **Machine Learning, Grafos e Graph Neural Networks (GNNs)**.

---

## 🎯 Objetivo

O projeto tem como objetivo:

* Prever risco de enchentes com base em dados históricos
* Modelar cidades como grafos
* Calcular rotas de fuga seguras
* Integrar IA para otimização dinâmica das decisões

---

## 🧠 Tecnologias

* Python
* Scikit-learn
* PyTorch + Torch Geometric
* NetworkX / OSMnx
* Java (Spring Boot)
* Web & Mobile

---

## 📂 Estrutura do Projeto

```
data/           # dados brutos e processados
assets/         # imagens e documentos
src/            # código principal (ML, grafos, features), aplicações (backend, web, mobile)

```

---

## ⚙️ Setup

### 1. Criar ambiente virtual

```
python3 -m venv venv
source venv/bin/activate
```

### 2. Instalar dependências

```
python -m pip install -r requirements.txt
```

---

## 🚀 Pipeline

1. Coleta de dados hidrológicos
2. Processamento e feature engineering
3. Modelagem de risco (ML / GNN)
4. Construção do grafo urbano
5. Cálculo de rotas seguras
